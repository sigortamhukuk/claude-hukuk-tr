# ihtarname-tr — Cold-start

Sorular:

1. KEP servis sağlayıcın? (TÜRKKEP / PTT KEP / Diğer)
2. KEP adresin?
3. Sık tercih ettiğin ihtar konuları? (Alacak / Fesih / Sigortacıya başvuru / Sair)
4. Standart talep süresi ne kadar? (7 / 10 / 15 / 30 gün)
5. Şablonların geçmiş ihtarnamelerden çıkarılsın mı? (Evet derse seed dosyaları iste)
